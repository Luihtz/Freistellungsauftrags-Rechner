# Guide zur Erstellung einer csv

1. Öffne einen Texteditor (z.B. Editor/Notepad++)

2. Eine mögliche Beispieldatei sieht so aus:

	```
	type,symbol,shares,price
	BUY,IE00BK5BQT80,50.000000,150.000000
	BUY,IE00BK5BQT80,30.000000,160.000000
	SELL,IE00BK5BQT80,-20.000000,170.000000
	BUY,IE00BK5BQT80,20.500000,165.000000
	```

  Kopiere als Beispiel diese Datei. Die Datei sollte dann aussehen, wie in "testdata.csv".

3. Gehe auf "Datei" > "Speichern unter" > Ordner der main datei nutzen > Dateityp "Alle Dateien" und .csv hinschreiben

4. Öffne die Datei in dem Streamlit Programm. Fertig :)
